Privacy policy: coleholden_ upload tool

Last updated: September 29, 2026

The coleholden_ upload tool is used only by its owner, Cole Holden, to upload videos to, and read analytics for, the YouTube channel @coleholden_.

YouTube API Services

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and your data is handled under the Google Privacy Policy.

What data is accessed

The tool accesses only the owner's own YouTube channel: it uploads the owner's videos, posts a comment on the owner's own videos, and reads the channel's own analytics (such as views and audience retention).

How data is stored and used

An OAuth refresh token and the channel's own analytics are stored locally on the owner's computer, with access restricted to the owner. Analytics are used only to decide which video formats to make next. No data is collected about any other person, and no data is shared with or sold to anyone.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, after which the locally stored token is deleted.
